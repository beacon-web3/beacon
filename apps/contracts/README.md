# Beacon Contracts

This directory is reserved for Beacon's future Solana program workspace.

Current status:

- No on-chain programs are implemented here yet.
- No Anchor, Pinocchio, or other Solana build workspace is configured yet.
- No program IDs, deployment targets, or mainnet/devnet addresses are defined.

Implementation boundaries:

- Do not treat this directory as a source of deployed contract behavior.
- Before adding contract code, align the implementation with the product specs in `docs/product/`, tokenomics drafts in `docs/tokenomics/`, and architecture direction in `docs/architecture/system-design.md`.
- Do not introduce reward, staking, treasury, badge, or governance mechanics beyond the documented specs.
